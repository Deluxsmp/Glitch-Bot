Security & Protection
  • /ban [target][Admin]
    Permanently bans malicious users with audit logs.
  • /kick [target][Mod]
    Instantly ejects disruptive members from the server.
  • /timeout [target] [time]
    Temporarily mutes a user for rule violations.
  • /antispam [status]
    Toggles automatic spam message mitigation.
  • /antinuke [status]
    Prevents mass channel/role deletion raids.
  • /automod-setup [filter]
    Deploys automated link and bad-word filters.
  • /whitelist [user/bot]
    Bypasses security triggers for trusted entities.
  • /set-roles [type] [role]
    Configures dedicated staff permission roles.
  • /set-log-channel [ch]
    Assigns audit log streams to specific channels.

  • /ticket-setup [cat] [role]

  • /verification-setup [role]
    Creates an interactive button-click verification gate.
