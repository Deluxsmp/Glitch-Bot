Command Guide

Explore all available slash commands categorized for easy navigation.

Moderation & Security
  • /ban [target]
    Permanently bans a disruptive user.
  • /kick [target]
    Kicks a user out of the server.
  • /timeout [target] [minutes]
    Temporarily mutes/timeouts a user.
  • /antispam [status]
    Enables/disables anti-spam protection.
  • /antinuke [status]
    Enables/disables anti-nuke protection.
  • /automod-setup [link] [timeout]
    Anti-link system setup.
  • /whitelist [user]
    Whitelists a user or bot.
  • /set-roles [type] [role]
    Assigns custom Admin or Moderator roles.
  • /set-log-channel [channel]
    Designates the moderation log channel.
Tickets & Systems
  • /ticket-setup [cat] [role] [title] [desc] [opt]
    Deploys advanced drop-down ticket panel.
  • /ticket-add [user] & /ticket-remove [user]
    Manage users in open tickets.
  • /welcome-setup [channel] [msg] [image]
    Automated welcome message system with {user} and {server} tags.
  • /verification-setup [role]
    Interactive verification panel with a button.
Utility & Fun
  • /rank
    Checks current level and XP progression.
  • /avatar [target]
    Displays high-resolution profile pictures.
  • /coinflip & /rps [choice]
    Mini-games (Coinflip and Rock Paper Scissors).
  • /poll [question] [options]
    Interactive emoji-based reaction poll.
  • /giveaway-start [prize] [duration]
    Server giveaway system.
  • /trigger-add [kw] [resp] & /trigger-remove
    Custom auto-responder keywords.
  • /embed-builder
    Custom rich embed modal builder.
  • /help
    Displays bot features summary.
